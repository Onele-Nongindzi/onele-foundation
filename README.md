# Onele Foundation website

A single-page website for Onele Foundation. No build step: plain HTML, CSS and two images.

## Publish free on GitHub Pages
1. Create a public repository called `onele-foundation`.
2. Upload `index.html`, `README.md` and the `images` folder (keep the folder).
3. Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
4. The site appears at `https://onele-nongindzi.github.io/onele-foundation/`.

## Update
- Text: edit `index.html` (each section has a heading you can search for).
- Contact email: search for `onelenongindzi@gmail.com`.
- When registration is approved, update the footer line about the Department of Social Development and add the NPO number.
